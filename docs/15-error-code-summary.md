# 15. 统一错误码总表 v1

## 1. 规则

`code = 0` 表示成功，非 0 表示失败。错误码按模块分段。后端应定义为常量，前端根据 code 做跳转、提示和特殊处理。

统一失败结构：

```json
{"code":40001,"message":"验证码错误或已过期","data":null}
```

## 14. 前端特殊处理

```text
10007 / 10008 -> 跳转登录
10009 / 42002 / 44105 / 44202 -> 跳转绑定手机号
10006 -> 显示无权访问
43201 -> 展示下级成员数量，不允许删除
44102 -> 提示邀请已过期
47003 -> 提示管理员账号已锁定
```
