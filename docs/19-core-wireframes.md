# 19. 核心页面线框图设计说明 v1

> 先固定 3 个核心页面：后台家庭成员管理页、小程序邀请确认页、前台家庭搜索页。

## 1. 后台家庭成员管理页

路径：

```text
/admin/families/:familyId/members
```

角色：

```text
ROOT_ADMIN / SUPER_ADMIN / PLATFORM_ADMIN
```

目标：

```text
维护某个家庭的成员节点、关系、绑定状态和邀请状态。
```

线框：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶部栏：Tree 家脉亲缘平台管理后台                    当前管理员：platform01  退出 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 面包屑：首页 / 家庭管理 / 张氏家族 / 成员管理                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 家族名称：张氏家族   姓氏：张   地区：山东济南   状态：正常   graph_version：12 │
├───────────────────────────────┬──────────────────────────────────────────────┤
│ 左侧：成员列表树                │ 右侧：成员详情 / 操作区                       │
│ [搜索成员姓名] [筛选绑定状态]    │ 成员ID：20001                                │
│ 顶点                            │ 姓名：张明远                                  │
│ └── 第一代                      │ 字辈：明                                      │
│     └── 第二代                  │ 性别：男                                      │
│         ├── 张明远  已绑定       │ 绑定状态：已绑定                               │
│         ├── 张明强  未绑定       │ 家庭角色：FOUNDER                              │
│         └── 张明亮  邀请中       │ [编辑] [删除] [标记无需绑定] [站内邀请]         │
│                                  │ [添加父亲] [添加母亲] [添加子女]               │
│                                  │ [添加兄弟姐妹] [添加配偶]                     │
└───────────────────────────────┴──────────────────────────────────────────────┘
```

成员节点展示：

```text
姓名｜性别｜出生年份｜字辈｜绑定状态
```

绑定状态：

```text
BOUND=已绑定
UNBOUND=未绑定
INVITING=邀请中
NOT_REQUIRED=无需绑定
```

关键交互：

```text
1. 删除存在下级成员：阻断提示，不能删除。
2. 删除 FOUNDER：提示先完成创始人转让。
3. 删除主成员且有配偶：二次确认是否连同配偶删除。
4. ADD_SIBLING 无父母节点：提示先创建父亲或母亲节点。
5. 数据库不保存 SIBLING。
```

## 2. 小程序邀请确认页

路径：

```text
/pages/invite/detail?token=xxx
```

流程：

```text
打开邀请链接
  ↓
读取邀请详情
  ↓
未登录 -> 微信快捷登录
  ↓
未绑定手机号 -> 绑定手机号
  ↓
展示邀请详情
  ↓
接受 / 拒绝
```

未登录状态：

```text
┌──────────────────────────────┐
│            邀请确认            │
├──────────────────────────────┤
│  你收到一个家庭成员绑定邀请      │
│  家庭：张氏家族                 │
│  成员：张明远                   │
│  请先使用微信登录后查看完整邀请。 │
│  [微信快捷登录]                 │
└──────────────────────────────┘
```

可确认状态：

```text
┌──────────────────────────────┐
│            邀请确认            │
├──────────────────────────────┤
│  家庭名称：张氏家族             │
│  家族姓氏：张                   │
│  地区：山东省济南市             │
│  成员姓名：张明远               │
│  性别：男                       │
│  出生日期：1990-01-01           │
│  籍贯：山东济南                 │
│  邀请人：张管理员               │
│  有效期至：2026-06-11 12:00     │
│  [拒绝]              [接受绑定] │
└──────────────────────────────┘
```

异常状态：

```text
邀请不存在
邀请已过期
邀请已接受
邀请已取消
目标成员已被绑定
```
