# 21. 微信小程序上架与发布检查清单 v1

> 小程序相关规则可能变化，最终以微信公众平台当时要求为准。

## 1. 账号准备

```text
小程序账号
小程序 AppID
主体信息
主体认证
小程序名称
小程序头像
小程序简介
服务类目
管理员与开发者权限
```

## 2. 服务器域名配置

微信公众平台需要配置：

```text
request 合法域名
uploadFile 合法域名，如有上传
downloadFile 合法域名，如有下载
socket 合法域名，如有 WebSocket
业务域名，如使用 web-view
```

本项目一期至少需要：

```text
request 合法域名：https://api.example.com
```

要求：

```text
使用 HTTPS
域名不能是 IP
证书有效
备案状态符合平台要求
修改域名后刷新开发者工具配置
```

## 3. 隐私保护指引

本项目涉及：

```text
手机号
微信 openid
微信 unionid，如使用
昵称
头像
姓名
性别
出生日期
籍贯
家庭关系
留言联系方式
```

隐私保护指引应说明：

```text
收集哪些信息
为什么收集
如何使用
保存期限
用户如何更正 / 删除
用户如何注销账号
联系方式
```

## 4. 用户协议与隐私政策

上线前应准备：

```text
用户服务协议
隐私政策
未成年人信息说明，如涉及
账号注销说明
个人信息更正和删除说明
联系方式
```

建议页面：

```text
/pages/agreement/user
/pages/agreement/privacy
/pages/account/cancel
```

## 5. 小程序页面检查

一期至少包含：

```text
首页
微信快捷登录
绑定手机号
家庭搜索
公开家庭主页
公开家庭树
我的家庭
家庭详情
成员列表树
邀请确认
加入家庭申请
个人中心
用户协议
隐私政策
注销账号
```

## 6. 登录与手机号绑定检查

```text
首次微信登录生成 PENDING_PHONE_BIND user
绑定新手机号成功
绑定已存在 ACTIVE 手机号触发账号合并
绑定 PENDING_CLAIM 手机号触发账号认领
合并 / 认领后旧 token 失效并要求重新登录
未绑定手机号不能加入家庭、留言、接受邀请
```

## 7. 邀请链接检查

```text
微信分享链接打开邀请页
未登录用户先微信登录
未绑定手机号用户先绑定手机号
已绑定用户可接受 / 拒绝邀请
过期邀请有明确提示
已接受邀请有明确提示
目标成员已被绑定有明确提示
```

## 8. 审核前自测

```text
首页可进入
搜索家庭正常
公开家庭主页正常
公开家庭树正常
微信登录正常
手机号绑定正常
邀请确认正常
加入家庭申请正常
个人中心正常
用户协议和隐私政策可访问
注销账号入口可访问
没有测试按钮、调试入口、假数据
```

## 9. 体验版测试

```text
上传体验版
添加体验成员
真机测试
测试不同微信账号
测试未绑定手机号流程
测试邀请分享流程
测试弱网和接口失败
修复问题后重新上传
```

## 10. 提交审核材料

通常需要：

```text
小程序名称
服务类目
页面截图
功能说明
测试账号，如审核需要
隐私保护指引
用户协议
备案信息，如平台要求
```

审核说明建议：

```text
本小程序用于家族资料管理、公开家庭展示、成员邀请和加入申请。
用户需绑定手机号后才能加入家庭、接受邀请和留言。
```

## 11. 发布后检查

```text
正式版可打开
正式 API 可访问
request 合法域名无报错
微信登录正常
手机号绑定正常
公开家庭可查看
operation_logs 正常写入
服务器日志无异常
```

## 12. 常见审核风险

```text
隐私政策不完整
收集手机号但隐私指引未说明
页面存在测试内容
服务器域名未配置或 HTTPS 证书异常
服务类目选择不匹配
功能描述和实际功能不一致
用户无法找到注销入口
审核人员无法完成登录或体验核心流程
```
