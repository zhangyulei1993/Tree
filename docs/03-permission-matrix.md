## 1. 角色体系

后台管理角色：

```text
ROOT_ADMIN
SUPER_ADMIN
PLATFORM_ADMIN
```

```text
FOUNDER
FAMILY_ADMIN
MEMBER
VISITOR
```

家庭角色存放在：

```text
family_member_user_links.family_role
```

## 4. 统一不可绕过规则

```text
1. 删除存在下级成员的节点。
2. 创建非法关系。
3. 给 NOT_REQUIRED 节点设置家庭权限。
4. 给未绑定 user 的节点设置 FOUNDER 或 FAMILY_ADMIN。
5. 同一个 family 中一个 user 绑定多个 ACTIVE member。
6. 同一个 member 被多个 ACTIVE user 认领。
7. 同一个 family 同时存在多个 FOUNDER。
8. 同一个 family 同时存在多个 PENDING 解散申请。
9. 同一个 family 同时存在多个 PENDING 创始人转让申请。
10. 同一个 member 同时存在多个 PENDING 邀请。
```
