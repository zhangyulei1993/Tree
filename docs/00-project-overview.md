# 00. 项目总览与一期边界

## 1. 项目定位

项目名称：**家脉亲缘**

项目目标：围绕家庭、家族、成员、亲属关系、公开展示、微信小程序与后台管理，形成一个可维护家庭结构、展示家族信息、支持成员认领与家庭互动的平台。

系统端包括：

```text
PC / H5 前台网站
微信小程序
管理后台
后端 API
数据库
```

## 2. 当前一期要做

```text
PC / H5 手机号注册登录
微信小程序快捷登录
微信小程序绑定手机号
后台预创建 / 派发账号
账号合并与账号认领
创建家庭

申请加入家庭
```

## 4. 重要原则

### 4.1 家庭成员不等于系统用户

```text
family_member 是家庭树节点。
user 是系统账号。
family_member 可以没有 user。
```

适用场景：

```text
已故成员
历史祖先
年长亲属
未成年人
失联成员
不愿注册者
不可抗力无法注册者
```

### 4.2 用户可以消失，家庭节点可以保留

用户注销、解绑、账号合并不会自动删除家庭树节点。

```text
user 可以注销或失效。
family_member 仍然保留在家庭树结构中。
```

### 4.3 一期家庭树不是关系网

一期只做列表树 / 层级树：

```text
顶点
第二排
第三排
第四排
……
```

不做动态称谓展示。称谓工具和关系网后续再做。

### 4.4 搜索与公开展示分离

```text
游客可以搜索所有正常状态家庭。
只有申请公开并审核通过的家庭，才展示公开主页和公开展示树。
```
