# 01. 核心业务规则

## 1. 家庭搜索与公开展示

### 1.1 家庭搜索

游客可以搜索：

```text
status = NORMAL
searchable = 1
```

搜索条件：

```text
家族名模糊搜索
家族姓氏
籍贯
地区
```

搜索结果展示：

```text
家族名称
家族姓氏
地址 / 籍贯
创始人姓名
家庭公开联系电话
家庭公开微信号
是否已公开展示
```

家庭公开联系方式可以为空；如果为空，可提示“请通过平台联系”。

### 1.2 公开展示

只有：

```text
families.public_display_status = APPROVED
```

的家庭可以展示公开主页和公开家庭树。

公开资料修改后直接生效，平台可以下架公开家庭，操作必须写日志。

---

## 2. 游客访问规则

游客可以：

```text
搜索正常状态家庭
查看搜索结果基础信息
查看当前公开家庭主页
查看当前公开家庭展示树
提交留言，留言审核后展示
```

游客不能：

```text
手动切换查看其他公开家庭树
申请加入家庭
创建家庭
查看完整家庭树
进行互动性成员操作
```

手动切换查看其他公开家庭树时：

```text
PC / H5：登录即绑定手机号
微信小程序：快捷登录后仍需绑定手机号
```

---

## 3. 家庭树规则

一期家庭树为列表树 / 层级树。

```text
不使用 centerMemberId 作为展示中心
不显示动态亲属称谓
不做复杂图谱
配偶作为附属信息展示
删除节点默认隐藏
```

添加关系时可以以某个成员作为当前操作节点，但这只是录入上下文，不是家庭树展示中心。

树接口建议同时返回：

```text
nodes
edges
tree
```

---

## 4. 成员录入规则

前端可以按当前操作节点选择：

```text
添加父亲
添加母亲
添加子女
添加兄弟姐妹
添加配偶
```

数据库保存客观关系：

```text
PARENT_CHILD
SPOUSE
```

不保存动态称谓。

### 4.1 添加兄弟姐妹

如果当前成员已有父母节点：

```text
可以直接从本人添加兄弟姐妹。
系统自动把新成员挂到同一父母下。
```

如果当前成员没有父母节点：

```text
提示先创建父母节点。
不允许直接创建孤立兄弟姐妹关系。
```

---

## 5. 无需绑定用户的成员节点

家庭成员节点可以有四种绑定状态：

```text
BOUND
INVITING
NOT_REQUIRED
UNBOUND
```

状态计算：

```text
存在 ACTIVE family_member_user_links -> BOUND
存在 PENDING family_invitations -> INVITING
user_binding_policy = NOT_REQUIRED -> NOT_REQUIRED
否则 -> UNBOUND
```

`NOT_REQUIRED` 适用于：

```text
已故成员
未成年人
年长不会使用手机者
失联成员
不愿注册者
不可抗力
历史祖先
其他
```

---

## 6. 删除成员规则

删除成员不需要平台审核，但必须遵守业务规则。

```text
存在子女或后代等下级成员时，禁止删除。
必须先处理下级关系。
```

如果删除主成员且有配偶：

```text
提示会连同配偶一起删除。
确认后主成员、配偶节点、配偶关系一起软删除。
```

如果删除配偶节点：

```text
只删除配偶节点，不影响主成员。
```

---

## 7. 邀请规则

平台管理员与家族管理员流程不同。

### 7.1 平台管理员

```text
填写节点信息
手机号搜索用户池
找到用户 -> 创建节点 + 站内邀请
找不到用户 -> 不能发邀请，只能选择“无需绑定用户”
```

平台管理员不能生成外部分享邀请链接。

### 7.2 家族管理员 / 家庭创始人

```text
创建或定位成员节点
生成分享邀请链接
通过微信等方式发送
用户点击链接查看详情
确认绑定前必须登录 / 注册 / 绑定手机号
接受后创建绑定
```

邀请有效期 7 天，访问时实时判断过期。

不同成员节点可以同时有 PENDING 邀请；同一个成员节点同一时间只能有一个 PENDING 邀请。

---

## 8. 用户申请加入家庭

用户主动申请加入家庭，主要由家庭创始人 / 家族管理员处理，平台管理员仅协助。

通过后：

```text
绑定已有 member 或创建新 member
创建 family_member_user_links
默认 family_role = MEMBER
```

拒绝后允许重新申请。

---

## 9. 家庭公开申请

家庭创始人和家族管理员可以申请公开。

平台管理员可以代家庭发起公开申请，也可以审核普通家庭公开申请，但不能审核自己发起的申请。

同一个 family 同一时间只能有一个 PENDING 公开申请。

下架公开家庭一期只写 operation_logs，不单独建下架表。

---

## 10. 游客留言

游客留言规则：

```text
允许匿名
联系方式不必填
留言内容必填
最多 1000 字
同一 IP 1 分钟最多 1 条
同一 IP 1 天最多 20 条
审核通过后直接展示
公开页按 created_at DESC 展示
```

---

## 11. 用户注销规则

用户注销分正常注销和特殊注销。

正常注销前应解除一切家庭身份：

```text
不是任何家庭创始人
没有 ACTIVE family_member_user_links
没有未完成的创始人转让 / 家庭解散 / 合并 / 认领流程
```

特殊注销，如死亡、长期失联、平台特殊处理：

```text
user 账号注销或失效
family_member 节点继续保留
```

注销时释放手机号：

```text
users.phone = NULL
users.phone_verified = 0
users.status = CANCELLED
```

手机号历史进入 `user_phone_history`。
