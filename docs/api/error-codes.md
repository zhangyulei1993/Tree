## Family Module Codes

以下代码当前定义在 `backend/internal/family/core/service/family_service.go`，不在共享 errors 包中，但 M7 接口会真实返回。

| Code | Message |
|---:|---|
| 42004 | 家庭姓氏不能为空 |
| 42006 | 当前账号状态不允许创建家庭 |
| 42101 | 家庭不存在 |
| 42103 | 家庭公开信息不可访问 |
| 42104 | 无权查看家庭详情 |
| 42201 | 无权修改家庭信息 |
| 42202 | 当前家庭状态不允许修改 |
| 46301 | 无权操作家庭解散申请 |
| 46302 | 当前家庭状态不允许申请解散 |
| 46303 | 家庭已有待处理的解散申请 |

注意：`surname` 带 Gin `required` 标签，缺失或空字符串通常先由 handler 返回共享码 `10001`；`42004` 主要覆盖通过绑定后再被 service trim 为空的情况，例如仅空格。
